# ChulipVideo 操作・開発手順

## 基本操作

1. 上部の選択ボタンまたはファイルのドロップで動画を開く。選択中のフルパスと動画情報を上部で確認できる。
2. 「トリミング範囲」の開始・終了欄、現在位置からの設定ボタン、タイムラインの緑/赤マーカーで区間を指定する。現在位置のマーカーは再生位置。
3. 左ドラッグでクロップを作成し、内部をドラッグして移動、枠をドラッグしてサイズを変更する。X/Y/幅/高さは元動画のピクセル単位。
4. 「エクスポート」の操作の軌跡・静止画出力・動画出力で、演出、静止フレーム・重複除外、PNG圧縮を設定する。
5. COPY、現在画像のPNG保存、PNG連番保存、MP4動画保存、GIFアニメ保存を使用する。書出しは下部の進捗欄から中断できる。

画面は上からソースツールバー、プレビュー、再生操作、トリミング範囲、クロップ範囲、エクスポート。編集機能を切り替えるタブはなく、主要操作を常時表示する。ウィンドウを広げるとプレビューが拡大する。

開始・現在・終了は`HH:mm:ss.fff`形式で表示する。秒数、`MM:SS.sss`、`HH:MM:SS.sss`でも入力でき、Enterまたは入力欄から移動すると反映する。時刻欄へ移ると再生を停止する。各時刻の左右に1秒の増減ボタンがある。無効な文字列は直前の値へ戻し、範囲外の値は動画の範囲に収める。

プレビューは元の比率を維持する。大きな動画はプレビューだけ縮小し、出力は指定したクロップ解像度を保持する。枠外を許可すると、動画のない部分を黒で埋める。

「座標固定」「寸法固定」でマウス・数値欄・プリセットからの変更を制約できる。「全体選択」とUndo/Redoは明示的な範囲の復元として使える。

プリセットの比率欄は、登録済みの解像度を16:9・4:3・1:1などで絞り込む。ドラッグ中の比率を固定する機能はShiftを使う。保存したプリセットはアプリ共通設定に残る。

## 再生とショートカット

| 操作 | 機能 |
| --- | --- |
| Space | 再生・停止 |
| ← / → | 0.1秒移動 |
| Ctrl + ← / → | 1秒移動 |
| Home / End | 選択区間の先頭・末尾へ移動 |
| Ctrl + Home / End | 動画の先頭・末尾へ移動 |
| Ctrl + O | 動画選択 |
| Ctrl + C / S | 現在のクロップ画像をコピー / PNG保存 |
| Ctrl + Z / Y | クロップを戻す / やり直す |
| I / O | 現在位置を開始 / 終了へ設定 |
| Alt + 矢印 | クロップを1px移動。Ctrl併用で10px |
| Shift + 矢印 | 中心を固定して各辺を1px伸縮。Ctrl併用で10px |
| ホイール / 中ドラッグ | 表示の拡大縮小 / パン |
| 中ダブルクリック | 表示をリセット |
| クロップ操作中のShift | 移動軸または比率を固定 |
| クロップ操作中のCtrl / Alt | 中心固定リサイズ / 10px刻み |

文字・数値欄の編集中は入力欄のキー操作を優先する。再生速度は-9.9～9.9倍。負数は逆再生。速度0の状態から再生を開始すると1倍になる。往復はループと併用する。

## 画像・動画の書出し

区間は開始を含み、終了を含まない。出力時は開始を直前のフレーム時刻、終了を直後のフレーム境界へ広げ、映像・演出・字幕の基準をそろえる（動画末尾を越えない）。たとえば10fpsで0.35～0.55秒を指定すると0.30～0.60秒の3フレームになる。可変FPS入力も表示されたFPSに合わせて一定FPS化する。

- PNGの「静止フレーム」は前後の画素が完全一致するフレームを選ぶ。境界は存在する隣接フレームと比較する。単独フレームも出力できる。
- 「重複を除外」は直前に保存した画像と比較する。比較は演出を描く前のクロップ画像で行う。
- 常に動く映像では静止抽出の保存枚数が0になる場合がある。全フレームを取りたい場合は静止抽出と同一画像除外を両方OFFにする。
- PNG連番は選択フォルダー内に新しい日時付きフォルダーを作成する。圧縮レベル0～9は可逆圧縮であり、画質は変わらない。
- MP4はH.264、GIFはパレット生成・適用で出力する。動画の音声再生・音声出力はPython版と同様に扱わない。
- MP4の奇数サイズは寸法を維持するためyuv444pを使う。一般的な再生互換性が必要な場合は幅・高さを偶数にする。
- 既存出力ファイルと同名の字幕は上書きしない。別名で保存する。書出し途中は一時領域を使い、完了した結果を保存先へ確定する。
- PNG・MP4・GIFの保存先に既存ファイルを選ぶと、上書き確認は出さずに別名の指定を求める。

## TSVと演出

動画と同名の`.tsv`を自動で読む。CapchunScreenの記録形式と、旧Python版の短いクリック表記に対応する。読み直す場合は「再読込」を使う。

```text
timestamp	frame	x	y	click	keys
0.000	0	100	80	L-Click	None
0.100	3	100	80	None	Ctrl,C
```

ポインター・クリック・字幕は設定で独立変更できる。「操作の軌跡」の「マウスポインタ」はポインターとクリックをまとめて切り替える。上部の「TSV」で対応する入力履歴を既定のアプリで開く。詳細設定は「ポインター・クリック」「入力字幕」「テーマ」「出力・FFmpeg」の順。下部の演出表示は色と形の見本。実時間の波紋・字幕フェードは動画上で確認する。

PNGとコピーは有効な演出を合成する。MP4/GIFは「動画へ焼込み」がONの場合に合成する。TSV/SRT/VTTは設定で個別に出力を選ぶ。入力TSVがない場合は字幕を生成しない。

出力TSVは切り出し開始を0秒・0フレームにし、座標もクロップ原点を引く。これにより生成動画を再編集してもポインターがずれない。PNG連番フォルダーでは`operations.tsv`等、動画では出力動画と同名の字幕ファイルになる。SRT/VTTも切り出し開始からの相対時刻。

## 設定ファイル

アプリ共通設定は`%LOCALAPPDATA%\KotorinToys\ChulipVideo\settings.json`。開発・試験では`--settings`で保存先を分けられる。

動画別設定は上部の「保存」で`<動画名>.chulip.settings.json`へ保存する。保存済みC#設定がなければPython版の`<動画名>.settings.json`を読み込む。Python版設定を自動上書きしない。編集の途中保存は明示的に行う。

FFmpegは設定、`CHULIPVIDEO_FFMPEG`、実行ファイル周辺の配置、PATHの順に検索する。開発用`.local/ffmpeg.exe`はDebugビルドだけが、実行ファイルから最初に見つかるリポジトリ直下（`tool.json`のある場所）に限って探す。カレントディレクトリや`C:\`直下などリポジトリ外の`.local`は使わない。設定画面ではパスを参照して選択できる。

Windowsのサインアウト・シャットダウン時は終了を妨げない。書き出し中なら中断し、アプリ共通設定だけ保存して閉じる。保存先に`.chulip-export-*`の一時フォルダーが残った場合は削除してよい。

色の設定は`#RRGGBB`で保存する。手編集などで不正な色があれば、読込時に既定色（空欄可の項目は空欄）へ戻し、他の設定はそのまま使う。

## 開発・テスト

```powershell
cd C:\develop\KotorinToys\tools\ChulipVideo
./dev/scripts/build.ps1
./dev/scripts/test.ps1
./dev/scripts/start.ps1 -Video 'C:\動画\sample.mp4'
```

テストは独立したコンソールプロジェクトで、実FFmpegによる素材生成・デコード・出力検証を行う。実行結果と素材は製品版から決めた`dev/history/vX.Y.Z/logs/<実行識別子>/`へ保存し、Git対象外とする。部品テストと実デスクトップ確認は別の証跡として記録する。

このフォルダーは独立Gitリポジトリで、KotorinToysの子としてGitリンク登録されている。単体ZIPの公開と本体の導入・更新カタログは別管理。[管理連携の仕様](kotorintoys-integration.md)も参照。
