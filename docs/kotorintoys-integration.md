# KotorinToys管理連携

ユーザー専用名前付きパイプで状態確認・既存画面の表示・正常停止に対応します。既存の設定保存・履歴・動画は移動しません。

- 通常起動は画面表示、`--startup`は画面非表示の常駐です。本体から「起動設定を開く」で表示できます。
- 二重起動は既存の同一EXEを前面化します。PIDと利用者を検証します。
- 動画の読込・描画・書き出し・終了処理中、およびモーダル画面表示中は管理停止を拒否します。操作完了後に再実行してください。
- テスト時は`--settings-dir <専用フォルダー>`または`--settings <JSONファイル>`で設定保存先を分離できます。
- KotorinToysからの開発実行に対応します。単体ZIPの公開と本体の導入・更新カタログは別管理であり、本体からの正式導入・更新は未登録です。
- キー一覧の本体連携は未実装のため、空の予約ファイルのみ置きます。実操作は製品の利用ガイドを参照してください。
