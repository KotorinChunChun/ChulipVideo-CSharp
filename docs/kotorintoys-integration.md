# KotorinToys管理連携

ユーザー専用名前付きパイプで状態確認・既存画面の表示・正常停止に対応します。既存の設定保存・履歴・動画は移動しません。

- 通常起動では画面を表示します。`--startup`を指定した場合は画面を表示せずに常駐し、本体の「起動設定を開く」で画面を表示できます。
- 二重起動は既存の同一EXEを前面化します。PIDと利用者を検証します。
- 動画の読込・書き出し・終了処理中、およびモーダル画面表示中は管理停止を拒否します。操作完了後に再実行してください。再生中（プレビュー描画中）の停止は受け付け、再生を止めて通常の終了処理で設定を保存します。
- テスト時は`--settings-dir <専用フォルダー>`または`--settings <JSONファイル>`で設定保存先を分離できます。
- KotorinToysからの開発実行に加え、0.2.1から本体対応Inno形式で正式導入・更新・削除に対応します。C#専用リポジトリの製品別配布台帳と固定hashを使います。[導入ガイド](install.md)を参照してください。
- キー一覧はまだ本体と連携していないため、連携用の空ファイルだけを置きます。操作方法は製品の利用ガイドを参照してください。
