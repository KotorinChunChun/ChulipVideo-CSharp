# C#版のインストールと削除

Windows 11 x64向け未署名開発版です。[C#版Releases](https://github.com/KotorinChunChun/ChulipVideo-CSharp/releases)の`ChulipVideo-0.2.1-setup.exe`を使用します。別リポジトリのPython版ChulipVideoとは別の配布です。.NET Desktop Runtimeを同梱します。KotorinToys 0.1.2以降からも導入・更新・削除できます。

利用者ごとにインストールし、スタートメニューに登録します。更新前にアプリが正常に停止したことと、更新対象の製品が一致することを確認します。読み込みや書き出しなどでアプリが終了を拒否した場合は、更新を中止します。既存ZIP版の設定・動画・画像は移動も削除もしません。ZIP版は別の場所に残るため、同時に起動せず、使う版を選んでください。

FFmpegは同梱しません。既存のFFmpegを設定画面で指定してください。設定の保存先と操作方法は[操作ガイド](guide.md)を参照してください。Windowsの「インストールされているアプリ」またはKotorinToysで削除できます。設定・履歴・動画・画像は保持します。

ビルド・自動試験・配布物のhash検証と、実デスクトップでの編集・動画書出しの受入は別の確認です。未署名の開発版であることを確認して利用してください。
