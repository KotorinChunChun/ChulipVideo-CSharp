# ChulipVideo v0.1.0 実装計画・報告

## 方針

C#/.NET 10 Windows Forms。FFmpegを外部プロセスで利用し、Pythonランタイムは必要としない。FFmpegは設定・環境変数・PATH・同梱位置から解決する。外部コマンドはArgumentListで組み立て、異常終了・キャンセルを成功扱いしない。

共通モデル、メディア入出力、オーバーレイと書出し、UIを分離する。プレビューは非同期デコード、書出しは連続フレーム取得で実装する。ファイルの上書きはダイアログまたは新規出力先で防ぐ。

## フェーズと担当

1. 親: Python機能調査、版別資料、共有モデル、独立Gitと最小ビルド。
2. メディア担当: FFmpeg探索・情報取得・シーク/連続フレーム取得・実メディア検証。出力担当: TSV・オーバーレイ・PNG/GIF/MP4・字幕。キャンバス担当: クロップ操作と設定画面。親: 主画面・設定保存・統合。並列担当は同じファイルを変更しない。
3. 親とレビュー担当: 統合ビルド、回帰、実出力の確認。問題修正後コミット。
4. 親: 最終デスクトップ操作と録画、利用手順・検証結果記録、親リポジトリにGitリンクを記録。
