# ChulipVideo v0.1.0 実装計画・報告

## 方針

C#/.NET 10 Windows Forms。FFmpegを外部プロセスで利用し、Pythonランタイムは必要としない。FFmpegは設定・環境変数・PATH・同梱位置から解決する。外部コマンドはArgumentListで組み立て、異常終了・キャンセルを成功扱いしない。

共通モデル、メディア入出力、オーバーレイと書出し、UIを分離する。プレビューは非同期デコード、書出しは連続フレーム取得で実装する。ファイルの上書きはダイアログまたは新規出力先で防ぐ。

## フェーズと担当

1. 親: Python機能調査、版別資料、共有モデル、独立Gitと最小ビルド。
2. メディア担当: FFmpeg探索・情報取得・シーク/連続フレーム取得・実メディア検証。出力担当: TSV・オーバーレイ・PNG/GIF/MP4・字幕。キャンバス担当: クロップ操作と設定画面。親: 主画面・設定保存・統合。並列担当は同じファイルを変更しない。
3. 親とレビュー担当: 統合ビルド、回帰、実出力の確認。問題修正後コミット。
4. 親: 最終デスクトップ操作と録画、利用手順・検証結果記録。親への登録は現在の取得規約を確認して判断する。

## Gitと依存関係

独立Gitのmainで管理。基盤`84d9221`、実装`08c0b87`。親KotorinToysの現在規約は公開先を.gitmodulesへ記載して再帰取得する構成のため、公開先未設定のこの新規リポジトリを不完全なGitリンクでは登録しない。子は指定場所に配置し、親のカタログ・既存変更・他ツールは変更していない。公開/親登録は別工程。

開発用FFmpegは既存Python環境のバイナリを`.local/ffmpeg.exe`へ複製。SHA-256は`2CE797A0F88D7F067180338FB227F7B1928EA727BD9A4D7A1D022F7C52AF71A3`。製品コードはPython絶対パスへ依存しない。FFmpegの設定・環境変数・配置探索を利用する。

末尾PTS取得には末尾約1秒の限定デコードを使い、時間・フレーム数・ログ量を制限する。取得できない入力は推定時刻を使い、読み込み時に注意を表示する。可変FPSは一定FPSへ正規化する。非常に長い動画・全コーデックの網羅試験は実施していない。
