# 0.2.2 セキュリティ点検・修正

2026-10-19。親KotorinToysから全公開プログラムの総点検を依頼された。設定・履歴と独立Gitを保持する。

- [x] ローカル動画内のプレイリスト経由の外部通信を禁止。FFmpegの入力をfile/pipeへ限定。
- [x] HLSがloopbackの検証待受へ接続する前に拒否されることを確認。既存メディア・出力・設定・管理・部品回帰とビルドすべて成功。既存試験フォルダー再利用の失敗は新規GUIDフォルダーで再検証して区別した。
- [x] 独立ZIPの梱包前にも秘密／実DB／PDB／旧.NET拒否ゲートを同梱し、構文と架空payloadを検証。配布物・署名・外部公開は未実施。製品版番号の更新は公開準備時に行う。

HTTP参照を含む動画は開けなくなる。ローカルMP4/MKV、GIF生成、パイプ出力は保持する。FFmpeg自体の未知の脆弱性や完全なOS隔離を保証するものではない。
