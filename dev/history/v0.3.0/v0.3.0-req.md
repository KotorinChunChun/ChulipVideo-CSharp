## 未実装

### 手順書（v0.3.0）

- [ ] R1（候補1）: 入力ログのクリック・ドラッグ・キー操作・文字入力から「ステップ」を自動抽出し、操作直前の落ち着いたフレームを1操作1枚で取得する。抽出結果を一覧で確認・修正（削除・結合・追加・フレーム前後調整・説明文編集）し、`<動画名>.chulip.steps.json`へ保存・復元できる。
- [ ] R2（候補2）: ステップを番号・説明文・画像付きの手順書としてMarkdown・HTML・Word（.docx）・PDFへ書き出す。既存出力を上書きしない。
- [ ] R3（候補3）: 静止判定と重複除外に許容差（色差しきい値・変化画素率）を設け、圧縮ノイズで静止場面を取りこぼさない。完全一致も選べる。
- [ ] R4（候補4）: 範囲と時間帯を指定するマスク（モザイク・ぼかし・塗りつぶし）を、プレビュー・コピー・PNG・PNG連番・MP4・GIF・ステップ画像・AI送信画像のすべてへ漏れなく適用する。
- [ ] R5（候補5）: ステップ画像へ番号バッジ・強調枠・矢印・文字の注釈を自動配置し、手動で追加・移動・削除できる。

### 動画演出（v0.4.0）

- [ ] R6（候補6）: 動画書き出しで、クリック地点へ滑らかに寄って戻る自動ズームを付ける。倍率・時間を設定でき、プレビューで確認できる。
- [ ] R7（候補7）: 入力も画面変化もない区間を検出し、カットまたは早送りして書き出す。字幕・TSVの時刻も対応させる。
- [ ] R8（候補8）: 入力ログの座標を補間・平滑化し、描画するポインターの動きをなめらかにする。クリック位置は実座標に合わせる。
- [ ] R11（候補11）: 1本の動画に複数の区間とマーカーを登録し、区間ごとの一括書き出しができる。

### 認識・AI（v0.5.0）

- [ ] R10（候補10）: ステップ説明文を生成AI（Claude）で作成できる。既定は無効で、実行ごとに送信内容を確認し、マスク適用後の画像だけを送る。説明文をオフラインの音声合成で読み上げ、MP4へナレーションとして入れられる。

### 共通

## 対象外

画面録画（CapchunScreenの担当）、外部ウィンドウ操作（ChunapTool）、手順書のクラウド共有・リンク公開・共同編集、Web版、ブラウザ拡張、対話型デモ。v0.2.0で対象外とした「音声対応」はR10のナレーションに限って対象とする（録音・元動画の音声は扱わない）。

## 決定事項

2026-10-31、設計書の[確認事項](v0.3.0-imp.md#確認事項)6件をすべて推奨案で確定した。

1. 外部依存: OCR・音声合成のため、ターゲットを`net10.0-windows10.0.19041.0`へ変える。AIには公式SDK（NuGet `Anthropic`）を採用する。どちらもv0.5.0（P8・P9）で導入し、それまでは入れない。SDKはAI機能の中だけで使い、セキュリティ診断の依存台帳へ追記する。
2. PDF: Microsoft Edgeのヘッドレス印刷を外部プロセスとして使う。Edgeがない環境では理由を表示し、HTMLの印刷を案内する。
3. 録画のカーソル: 映り込む場合、R8の平滑化の効果は描画ポインターに限ると明記する。CapchunScreenで映り込みと、カーソルを消す設定の有無をP5の前に確認する（調査は未実施）。
4. 静止判定: 既定を許容差あり（色差8・変化率0.05%）へ変える。「完全一致」を選択肢として残し、v0.3.0のリリース告知に出力枚数が変わりうることを書く。
5. AI送信: 既定は無効、実行ごとに送信内容を確認し、マスク適用後の画像だけを送る。実際に使い始める前に社内規程を確認する。
6. リリース区切り: v0.3.0（手順書）・v0.4.0（動画演出）・v0.5.0（認識・AI）の3段階。
